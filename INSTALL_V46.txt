Changes
- Selecting a question in the question list preserves the list's scroll position and restores the page position within the available page height.
- Highlight is beside Bookmark. Turn it on, then select text in the question to highlight it automatically. Turn it off to select text normally. Clear Highlights removes marks from the current question.
- Highlights save per question in this browser, including when you revisit or reload. They do not sync between devices.
- Question settings now include All difficulties, Standard and Harder. This works alongside question type, topic, question history and session length.
- Existing V45 answers and bookmarks are retained. No medical content has changed.

The footer now reads Version 46. If the browser still shows an older version after deployment, refresh the page.
